### ⚡ Nitro

Write a component's logic in **PHP** and its view in **Blade, Vue, React, Solid or Svelte**. Nitro compiles the PHP to JavaScript that runs in the browser, and calls the server only when you ask it to.

```bash
composer require nitro/nitro
```

[Documentation](https://www.nitrophp.com) · [GitHub](https://github.com/nitroframework/nitro) · [Packagist](https://packagist.org/packages/nitro/nitro)
